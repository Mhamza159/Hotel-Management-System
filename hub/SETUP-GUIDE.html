1. System kaise kaam karta hai

Hotel ka WiFi / Router (internet ki zaroorat NAHI) | +---------------+----------------+-----------------+ | | | | HUB LAPTOP Reception Housekeeping Manager (hamesha ON) laptop laptop laptop database + Staff app Staff app Staff app backend
  • Hub laptop par hotel ka saara data hota hai (rooms, bookings, staff, payments). Ye hamesha on rehta hai.
  • Staff laptops par "Grand Horizon Staff" app chalti hai jo WiFi ke zariye Hub se baat karti hai.
  • Sab laptops ka ek hi WiFi/router par hona zaroori hai. Internet chahiye nahi.
  • Website (guests ki online booking) internet par chalti hai. Cloud sync har 15 second me Hub aur website ka data aapas me milata hai (tafseel: hissa 9 aur 10).

2. Shuru karne se pehle

  • ☐ Hub laptop: Windows 10/11, charger hamesha laga (behtar: UPS)
  • ☐ Sab laptops ek hi WiFi se jud sakte hon
  • ☐ Setup folder: GrandHorizon-Hotel-Setup-0.2.0 (Hub laptop par) — ya USB par copy
  • ☐ Staff laptops ke liye USB jis me ye file ho: staff-app\GrandHorizonStaff-Setup-0.2.0.exe
  • ☐ Admin ke liye ek email aur mazboot password (10+ harf, harf aur number dono)
Behtar: router ki settings me Hub laptop ko fixed IP (DHCP reservation) dein. Warna IP badalne par staff apps ko naya address dena padega.

3. Hissa A — Hub laptop setup

Option 1: Developer laptop ko Hub banana (jis par project code bhi hai)

Ye port 5100 use karta hai taake development backend (port 5000) se na takraye.

  1. 1File Explorer me setup folder kholein: GrandHorizon-Hotel-Setup-0.2.0
  2. 2Setup-This-Laptop-As-Hub.cmd par double-click karein.
  3. 3Windows poochhe "Allow this app to make changes?" → Yes. Neeli window khulegi.
  4. 4Agar purana test Hub laga hai to wo poochhega Type DELETE to continue → DELETE likh kar Enter. (Purana test data mit jayega.)
  5. 5Admin account banayein: Full name, Email, Password (do dafa).
  6. 6Aakhir me likha aayega Staff app Hub URL: http://192.168.x.x:5100 aur MUKAMMAL. Ye URL upar box me likh lein.

Ye script khud ye bhi karti hai: WiFi ko Private banana (taake doosre laptops aa sakein) aur charger par laptop ka sleep band karna.

Ye sirf pehli dafa ke liye hai. Hub ban jane ke baad ise dobara chalane se Hub ka data mit sakta hai — update ke liye hissa 8 ki "Naya version" command use karein.

Option 2: Kisi alag PC ko Hub banana

  1. Poora setup folder us PC par copy karein (jaise C:\GrandHorizon-Setup).
  2. Install-Hub.cmd par double-click → Yes. (Port 5000 use hota hai.)
  3. Admin account banayein, URL note karein.
  4. Agar window kahe ke network "Public" hai, to jo command wo dikhaye wo admin PowerShell me chalayein.
  5. Settings → System → Power: Sleep = Never (jab charger laga ho).
Install ke liye internet nahi chahiye. Saari files setup folder me hain, aur har file ka checksum check hota hai.

Hub laptop par bhi yehi app install kar sakte hain (admin kaam ke liye).

5. Hissa C — Pehla din (super-admin)

  1. Login: Staff app me super-admin email/password se.
  2. Rooms: Room Inventory → har room: number, type, price, capacity, photos.
  3. Staff accounts: Staff & Roles → har bande ka alag account (receptionist ya housekeeping), password kam az kam 8 harf.
  4. Permissions: PBAC Matrix → staff chunein → zaroori permissions on/off → Save Permissions (Save ke baghair kuch nahi badalta).
  5. Har staff ko unka email aur password khud dein; share na karne ko kahein.
Kisi ki permissions badlein to us staff member ko logout karke dobara login karne ko kahein, taake nayi permissions foran lag jayein.

8. Hub ki dekh-bhal

Ye commands Hub laptop par admin PowerShell me chalti hain (Start → "PowerShell" → right-click → Run as administrator).

Status check (sab theek hai?)

powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\hub-status.ps1"

Services Running, API Healthy, Network Private hona chahiye. Isi me staff app ka Hub URL bhi likha hota hai.

Backup

  • Har raat 02:00 baje khud: C:\ProgramData\GrandHorizonHub\backups (aakhri 14 din).
  • Abhi backup lena ho:
powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\backup-hub.ps1"
Hafte me ek dafa backups folder ki copy USB par bhi rakhein — laptop kharab ho to data bach jayega.

Hub ka IP address check karna

Router kabhi Hub ka IP badal deta hai — tab staff app "Hub tak nahi pohnch saka" dikhati hai.

Hub laptop par (koi bhi PowerShell):

KaamCommand
Poora address jo staff app me daalna hai ("Staff app Hub URL" wali line)powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\hub-status.ps1"
Sirf IP (WiFi wali IPv4 Address line)ipconfig | findstr IPv4
IP aur WiFi ka naam ek saathGet-NetIPConfiguration | Select-Object InterfaceAlias, @{n='IP';e={$_.IPv4Address.IPAddress}}, @{n='WiFi';e={$_.NetProfile.Name}}

Address: http://<IP>:<port> — is laptop wala Hub http://192.168.18.140:5100 (port 5100), alag Hub PC http://<IP>:5000.

Staff laptop se check (IP/port apne Hub ke hisaab se):

IP badal gaya ho to: har staff laptop par File → Hub Connection… → naya address → Test → Save.

IP ko mustaqil fix karna (behtar)

  1. Hub laptop par ipconfig /all → WiFi adapter ka Physical Address (MAC, jaise A1-B2-C3-…) note karein.
  2. Browser me router ka page kholein (ipconfig me Default Gateway, aam taur par 192.168.1.1 ya 192.168.18.1) aur login karein.
  3. DHCP Reservation / Address Reservation / Static Lease dhoondein → is MAC ke liye abhi wala IP (jaise 192.168.18.140) reserve → Save.

Router ka menu har company ka alag hota hai — mushkil ho to router ka model likh kar "DHCP reservation" search karein.

Services restart

Restart-Service GrandHorizonHubApi
Restart-Service GrandHorizonMongo

Dono ka haal: Get-Service GrandHorizonMongo, GrandHorizonHubApi (dono Running honi chahiye).

Logs (masla ho to): C:\ProgramData\GrandHorizonHub\logs — khaas taur par GrandHorizonHubApi.err.log.

Backup se data wapis lana (restore)

Restore Hub ka abhi ka saara data purane backup se badal deta hai. Cloud sync on ho to pehle developer se baat karein.

Admin PowerShell me ek ek line (is laptop par port 27100, alag Hub PC par 27017; file ka naam backups folder se):

Stop-Service GrandHorizonHubApi
& "C:\Program Files\GrandHorizonHub\runtime\tools\bin\mongorestore.exe" --uri="mongodb://127.0.0.1:27100/?directConnection=true" --gzip --archive="C:\ProgramData\GrandHorizonHub\backups\hub-YYYYMMDD-HHMMSS.archive.gz" --drop
Start-Service GrandHorizonHubApi

Naya version (update) — data mehfooz rehta hai

Naya setup folder mile to us folder me jayein aur admin PowerShell me ye chalayein. Data, accounts, bookings aur sync key (hub.env) wesi ki wesi rehti hai — sirf program badalta hai.

cd "C:\GrandHorizon-Setup"

Is developer laptop wala Hub:

powershell -ExecutionPolicy Bypass -File .\hub\install-hub.ps1 -ApiPort 5100 -MongoPort 27100 -SkipAdmin

Alag Hub PC (default ports):

powershell -ExecutionPolicy Bypass -File .\hub\install-hub.ps1 -SkipAdmin

Phir staff laptops par naya staff-app\GrandHorizonStaff-Setup-<version>.exe chala dein.

Khabardar: ab jab ye laptop asal Hub hai, Setup-This-Laptop-As-Hub.cmd dobara na chalayein — wo purane Hub ko data samait mita deta hai (Type DELETE poochhe to window band kar dein). Update ke liye sirf upar wali command.

Hub hatana

powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\uninstall-hub.ps1"

Data rakhta hai. Sab mitana ho to aakhir me -RemoveData lagayein (DELETE poochhega).

9. Cloud sync — website aur Hub ka rabta

Hub ka sync agent har 15 second me internet par website ke backend se data ka len-den karta hai. Dono taraf ek hi sync key lagi hoti hai (Vercel par SYNC_SHARED_KEY, Hub par hub.env me).

Haal check

  • Hub par status: hub-status.ps1 (hissa 8) → "Cloud sync" me last sync haal hi ka ho.
  • Website ko Hub dikh raha hai? Jawab me "hubOnline":true aana chahiye:
curl.exe -s https://hotel-backend-api-zeta.vercel.app/api/v1/sync/availability

Sync on karna (pehli dafa, ya naye Hub par)

  1. 1Nayi key banayein — lambi key aayegi, use select karke Enter (copy) aur Notepad file me save kar lein: 
    powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\configure-sync.ps1" -GenerateKey
  2. 2Vercel → hotel-backend-api → Settings → Environment Variables → SYNC_SHARED_KEY:
    • Naya ho to Add: Key me SYNC_SHARED_KEY (naam), Value me key, Type Secret, Environment Production → Save.
    • Pehle se ho to us ki line par ⋯ → Edit → Value me nayi key → Save. (Value box me dikhne wala sk_live_… sirf hint hai.)
  3. 3Deployments → sab se upar wale deploy par ⋯ → Redeploy → "Ready" ka intezar.
  4. 4Hub ko jorein — key maange to Notepad se copy, right-click (kuch nazar nahi aayega, ye normal hai), phir Enter: 
    powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\configure-sync.ps1" -CloudUrl https://hotel-backend-api-zeta.vercel.app
    Kamyabi par likha aayega: Cloud accepted the key … Cloud sync is on.
ErrorMatlab
must be at least 32 charactersKey paste nahi hui. Command dobara chalayein, is dafa right-click ya Ctrl + V.
rejected / 401Vercel par wohi key save nahi hui, ya Redeploy abhi "Ready" nahi hua.

Key bhool gaye ya leak ho gayi

Key kahin dobara parhi nahi ja sakti. Upar ke chaaron steps dobara karein (nayi key → Vercel par Edit → Redeploy → Hub par -CloudUrl). Key kabhi screenshot ya chat me na bhejein.

Sync band karna

powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\configure-sync.ps1" -Disable

Hub hotel ke andar chalta rahega; website se data milna ruk jayega.

Vercel par sync settings

VariableKya
SYNC_SHARED_KEYHub wali key (zaroori)
HUB_OFFLINE_BOOKING_GATENa lagayein = Hub offline ho tab bhi website booking chalti rahe (abhi yahi chal raha hai). true = Hub offline ho to website booking band.

10. Data ka flow (online booking se staff tak)

GUEST (mobile/laptop) HOTEL KE ANDAR (WiFi / LAN) Website (Vercel) HUB laptop | - Hub API (backend) Cloud backend <== har 15 sec sync ==> - Hub database | (internet) - Sync agent Atlas database (cloud) ^ | WiFi (internet nahi chahiye) Staff app Staff app (reception) (housekeeping)

Staff app kabhi website se seedha baat nahi karti — sirf Hub se.

A) Guest website par booking karta hai

  1. 1Guest website par room aur dates chun kar Book dabata hai.
  2. 2Cloud backend price khud calculate karta hai, room un dates ke liye lock karta hai aur booking save karta hai. Guest ko BK-XXXX confirmation milti hai.
  3. 3Hub ka sync agent (har 15 sec) cloud se nayi booking aur guest account le aata hai.
  4. 4Hub check karta hai: room khali hai to Hub bhi room lock kar leta hai. Room hotel me pehle se bika ho to booking par booking conflict lag jata hai.
  5. 5Staff app me booking ~20–30 second me aa jati hai (page refresh/dobara kholein). Header ka sync badge khud update hota hai.
  6. 6Guest hotel aata hai: check-in, payment — sab Hub me save hota hai aur agle sync par website par bhi status badal jata hai.

B) Staff hotel ke andar kaam karta hai

  1. 1Walk-in, check-out, safai, price — staff app WiFi par Hub ko bhejti hai, Hub foran save karta hai (internet nahi chahiye).
  2. 2Agle sync me Hub ye tabdeeliyan cloud ko bhejta hai.
  3. 3Website par woh room un dates me available nahi dikhta; price/room ki tabdeeli bhi website par aa jati hai.

C) Jab kuch band ho jaye

Kya huaKya hota hai
Hotel ka internet bandStaff app normal chalti hai. Website bhi booking leti rehti hai. Internet aate hi dono taraf ka data khud mil jata hai.
Internet band ke dauran website ne wohi room bech diya jo reception ne diyaSync par us website booking par booking conflict (hotel ki booking jeetti hai). Staff app me laal badge → front desk doosra khali room allot kare, ya cancel.
Hub laptop band / so gayaStaff app nahi chalegi. Website chalti rehti hai. Hub on hote hi sab sync.
WiFi / router bandStaff laptops Hub tak nahi pohnchte. Router on hote hi app chal padti hai.

Qaide

  • Hub hakim hai: kamron ka faisla hotel karta hai; takrao me hotel ki booking jeetti hai.
  • Ek hi record dono taraf badla ho to jo baad me badla, woh jeetta hai.
  • Same email ka account ya same number ka room dono taraf alag bana ho to hotel (Hub) wala rehta hai aur website wala us me mil jata hai (us ki bookings bhi). Is liye website par admin login Hub wale password se hota hai.
  • Website par bane guest accounts Hub par aate hain, aur Hub ke staff accounts website par bhi login kar sakte hain.
  • Hub par upload ki gayi room photo internet milte hi Cloudinary par jati hai, phir website par dikhti hai.

11. Naya staff laptop jorna / hatana

Staff laptop par sirf app install hoti hai — data Hub par rehta hai. Shart: staff laptop aur Hub ek hi WiFi/router par hon.

  1. 1Installer: setup folder ka staff-app\GrandHorizonStaff-Setup-<version>.exe USB par copy kar ke naye laptop par le jayein. (Developer laptop par ye desktop\dist\ me bhi hai.)
  2. 2Install: double-click. "Windows protected your PC" aaye to More info → Run anyway.
  3. 3Hub address: is laptop wala Hub http://192.168.18.140:5100; alag Hub PC ka address woh jo install ke aakhir me print hua (jaise http://192.168.1.10:5000). Test → "Connected" → Save.
  4. 4Account: super-admin Staff & Roles me naya account banaye (receptionist / housekeeping), phir PBAC Matrix me permissions → Save.
  5. 5Login: staff apne email/password se.

Test fail ho to

  • Dono laptop ek hi WiFi par hain? Hub laptop on hai, so to nahi raha?
  • Address me http:// aur sahi port (:5100 ya :5000) hai?
  • Hub par services: Get-Service GrandHorizonMongo, GrandHorizonHubApi → dono Running.
  • Hub ka network Private ho — Public ho to Hub par admin PowerShell me: 
    Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private

Staff laptop hatana

Windows Settings → Apps → Grand Horizon Staff → Uninstall. Data Hub par mehfooz rehta hai. Us staff ka account Staff & Roles se band/delete kar dein.

12. Hub ko doosre PC par shift karna

Sab se zaroori qaida: purana aur naya Hub kabhi ek saath cloud se jure na hon. Neeche ki tarteeb bilkul isi tarah follow karein.
Tayyari:
  • ☐ Setup package ka folder (USB me)
  • ☐ Sync key wali Notepad file
  • ☐ USB jis me backup copy ho sake
  • ☐ Naya PC: router se cable, charger/UPS, router me fixed IP (DHCP reservation)

Step 1 — Purane Hub par (admin PowerShell)

  1. Staff ko kaam rokne ka bolein; sab staff apps band. Is ke baad purane Hub par koi booking na ho.
  2. Sync poora hua? "Cloud sync" me last sync haal hi ka ho: 
    powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\hub-status.ps1"
  3. Taaza backup: 
    powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\backup-hub.ps1"
  4. C:\ProgramData\GrandHorizonHub\backups se sab se naya hub-YYYYMMDD-HHMMSS.archive.gz USB par copy karein.
  5. Purane Hub par sync band: 
    powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\configure-sync.ps1" -Disable
  6. Purane Hub ki services rokein: 
    Stop-Service GrandHorizonHubApi, GrandHorizonMongo

Step 2 — Naye PC par install (admin PowerShell)

  1. Setup folder naye PC par copy karein, jaise C:\GrandHorizon-Setup.
  2. cd "C:\GrandHorizon-Setup"
  3. -SkipAdmin kyunki admin account backup ke saath aa jayega (ports 5000 / 27017): 
    powershell -ExecutionPolicy Bypass -File .\hub\install-hub.ps1 -SkipAdmin
  4. Aakhir me print hua Hub address (jaise http://192.168.1.10:5000) likh lein.

Step 3 — Backup se data daalein (ek ek line)

USB wala backup naye PC par copy karein, jaise C:\GrandHorizon-Setup\hub-YYYYMMDD-HHMMSS.archive.gz (asal naam likhein):

Stop-Service GrandHorizonHubApi
& "C:\Program Files\GrandHorizonHub\runtime\tools\bin\mongorestore.exe" --uri="mongodb://127.0.0.1:27017/?directConnection=true" --gzip --archive="C:\GrandHorizon-Setup\hub-YYYYMMDD-HHMMSS.archive.gz" --drop
Start-Service GrandHorizonHubApi

Backup ke saath sync ka record bhi aata hai, is liye naya Hub wahin se aage chalta hai jahan purana ruka tha.

Step 4 — Naye Hub ko cloud se jorein

powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\configure-sync.ps1" -CloudUrl https://hotel-backend-api-zeta.vercel.app

Wohi Notepad wali key (right-click, Enter). Nayi key ki zaroorat nahi.

Step 5 — Network, power, check

Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private

Laptop ho to charger par sleep band:

powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0

Haal (services Running, cloud sync on) aur website ko Hub dikh raha hai ("hubOnline":true):

powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\hub-status.ps1"
curl.exe -s https://hotel-backend-api-zeta.vercel.app/api/v1/sync/availability

Step 6 — Staff apps ka address badlein

Har staff laptop: File → Hub Connection… → naya address → Test → Save. Sab ko ek dafa dobara login karna hoga (naye Hub ki security keys nayi hain; email/password wohi).

Step 7 — Purana Hub hatayein (1–2 din baad, sab theek chalne par)

powershell -ExecutionPolicy Bypass -File "C:\Program Files\GrandHorizonHub\scripts\uninstall-hub.ps1"

Data rakhta hai (emergency backup). Bilkul saaf karna ho to aakhir me -RemoveData (DELETE likhna padta hai).

Kuch ghalat ho jaye: naye Hub par configure-sync.ps1 -Disable, phir purane Hub par Start-Service GrandHorizonMongo, GrandHorizonHubApi aur -CloudUrl se dobara jorein. Purana data wahan mehfooz hai.
