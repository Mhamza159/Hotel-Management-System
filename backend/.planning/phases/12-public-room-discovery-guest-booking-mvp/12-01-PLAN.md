<objective>
Execute Phase 12: Public Room Discovery & Guest Atomic Booking Flow (MVP):

### Task 1: Room & Booking HTTP Services (`room.service.js` & `booking.service.js`)
- `roomService`:
  - `getAvailableRooms(params)`: `GET /rooms/available`
  - `getRoomDetails(id)`: `GET /rooms/:id`
  - `getRoomReviews(id, params)`: `GET /rooms/:id/reviews`
- `bookingService`:
  - `createBooking(payload)`: `POST /bookings` (automatically attaches `Idempotency-Key`)
  - `getMyBookings(params)`: `GET /bookings/my`
  - `getBookingById(id)`: `GET /bookings/:id`
  - `downloadInvoice(id)`: `GET /bookings/:id/invoice` (blob download)
  - `requestCancellation(id, { reason })`: `POST /bookings/:id/cancel-request`

### Task 2: Layout & Guest Navigation (`Navbar.jsx`, `Footer.jsx`, `GuestLayout.jsx`)
- `<Navbar />`: Brand logo, navigation links (`Explore`, `Suites`, `Amenities`), and auth-aware status (sign-in buttons or user menu with role link and sign-out).
- `<Footer />`: Brand details, address, contact, awards, and terms.
- `<GuestLayout />`: Responsive container wrapping Navbar + Page Content + Footer.

### Task 3: Search Widget & Room Card (`SearchWidget.jsx` & `RoomCard.jsx`)
- `<SearchWidget />`: Check-in date, check-out date, room type dropdown, guests counter. Persists dates in `useBookingDraftStore` and navigates to `/rooms`.
- `<RoomCard />`: Framer Motion `layoutId="room-img-${room._id}"`, photo preview, room type badge, capacity pills, price per night, and "Explore Suite" button.

### Task 4: Landing Page (`LandingPage.jsx`)
- Asymmetric hero with Fraunces serif display heading, ambient skyline SVG silhouette, floating `<SearchWidget />`, featured suites showcase, and hotel highlights.

### Task 5: Room Catalog & Detail (`RoomCatalogPage.jsx` & `RoomDetailPage.jsx`)
- `RoomCatalogPage`: Staggered card reveal (60ms offset), date and type filter bar, and empty state directive when no rooms match.
- `RoomDetailPage`: Shared-element hero transition, image gallery, full amenities list, price breakdown, and "Reserve Suite" CTA linking to `/checkout`.

### Task 6: Atomic Checkout & Confirmation (`CheckoutPage.jsx`)
- Multi-step flow: Summary of selected room(s), check-in/out dates, guest details, special requests, and payment method selector (`cash` / `offline-card`).
- Dispatches `bookingService.createBooking` with `<KeycardLoader />` sweep.
- On success: Renders confirmation card with real `bookingReference` (`GRH-...`) and download receipt button.

### Task 7: Integration & Build Verification
- Mount routes in `client/src/App.jsx`.
- Run `npm run build` in `client/`.
</objective>
