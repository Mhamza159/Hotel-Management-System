Execute Phase 9: Polish & Cross-Cutting Concerns (Final Phase):

### Task 1: Joi Input Validation Engine (`validate.middleware.js`)
- Implement `src/middlewares/validate.middleware.js` to inspect `req.body`, `req.query`, and `req.params`.
- On validation failure, reject with standard HTTP 422 Unprocessable Entity and an array of informative error messages.
- On success, sanitize and assign parsed values back to `req`.

### Task 2: Domain Validation Schemas & Route Integration
- Create schemas for:
  - `src/validations/auth.validation.js`: register, login, refreshToken, updateRole, updatePermissions.
  - `src/validations/room.validation.js`: createRoom, updateRoom, updateHousekeeping, searchRooms.
  - `src/validations/booking.validation.js`: createBooking, applyCoupon, cancelBooking.
  - `src/validations/desk.validation.js`: recordPayment, checkIn, checkOut.
  - `src/validations/engagement.validation.js`: createReview, joinWaitlist, toggleWishlist.
  - `src/validations/chat.validation.js`: userMessage, staffMessage, adminMessage, confirmAction.
- Integrate validation middleware across routes without breaking existing integration tests.

### Task 3: Security Hardening & Rate Limiting (`rateLimiter.middleware.js`)
- Implement `src/middlewares/rateLimiter.middleware.js`:
  - `authLimiter`: 5-10 requests per 15-minute window for auth routes.
  - `apiLimiter`: 100-200 requests per 15-minute window for general API routes.
  - Auto-bypass in `process.env.NODE_ENV === 'test'` to ensure lightning-fast test execution.
- Ensure Helmet headers (`X-Content-Type-Options`, `X-DNS-Prefetch-Control`, `X-Frame-Options`, etc.) are mounted and active in `src/app.js`.

- Run complete test suite (`npm test`) across all 21 test suites ensuring 100% pass rate.
