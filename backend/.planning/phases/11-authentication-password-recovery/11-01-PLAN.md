<objective>
Execute Phase 11: Authentication & Password Recovery with Full Backend Integration:

### Task 1: Auth Service (`client/src/services/auth.service.js`)
Implement `authService` using the configured `api` Axios client:
- `login({ email, password })`: `POST /auth/login`
- `register({ name, email, password, phone })`: `POST /auth/register`
- `getMe()`: `GET /auth/me`
- `forgotPassword({ email })`: `POST /auth/forgot-password`
- `resetPassword({ token, password })`: `POST /auth/reset-password`
- `logout()`: Clears `useAuthStore` session and redirects

### Task 2: Auth Layout (`client/src/layouts/AuthLayout.jsx`)
- Asymmetric/centered luxury dark frame with custom ambient SVG hotel skyline background.
- Clean header link to return to home page (`/`).
- Card container with `--surface` background, subtle border, and gold accents.

### Task 3: Login Page (`client/src/pages/public/LoginPage.jsx`)
- React Hook Form + Zod validation schema.
- Password reveal toggle button.
- Submits credentials to `authService.login`.
- On success: Saves `{ user, tokens }` in `useAuthStore`.
- Role-based automatic redirect:
  - `user` (Guest) -> `/dashboard` (or previous protected route location)
  - `receptionist` -> `/desk`
  - `housekeeping` -> `/housekeeping`
  - `super-admin` -> `/admin/analytics`
- Links to `/register` and `/forgot-password`.

### Task 4: Registration Page (`client/src/pages/public/RegisterPage.jsx`)
- Fields: Full Name, Email, Phone (optional), Password, Confirm Password.
- Zod schema requiring minimum 8 chars, 1 uppercase, 1 lowercase, 1 digit.
- Submits to `authService.register`, sets store, and redirects to `/dashboard`.

### Task 5: Password Recovery Flow (`ForgotPasswordPage.jsx` & `ResetPasswordPage.jsx`)
- `ForgotPasswordPage.jsx`: Accepts email, calls `authService.forgotPassword`, displays enumeration-safe reassurance message.
- `ResetPasswordPage.jsx`: Reads `?token=...` from URL search params. Accepts new password and confirm password. Calls `authService.resetPassword`. On success, redirects to `/login` with success banner.

### Task 6: Routing & Verification
- Mount routes in `client/src/App.jsx`.
- Run production build `npm run build` in `client/`.
</objective>
