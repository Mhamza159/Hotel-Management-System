<objective>
Execute Phase 17: Guest Portal, Stays Management & Engagement:

### Task 1: Engagement HTTP Service (`engagement.service.js`)
- `getLoyaltyBalance()`: Calls `GET /api/v1/loyalty/balance`.
- `getWishlist()`: Calls `GET /api/v1/wishlist`.
- `addToWishlist(roomId)`: Calls `POST /api/v1/wishlist/:roomId`.
- `removeFromWishlist(roomId)`: Calls `DELETE /api/v1/wishlist/:roomId`.
- `getWaitlists()`: Calls `GET /api/v1/waitlist`.
- `joinWaitlist(payload)`: Calls `POST /api/v1/waitlist`.
- `cancelWaitlist(id)`: Calls `DELETE /api/v1/waitlist/:id`.
- `createReview(payload)`: Calls `POST /api/v1/reviews`.

### Task 2: Submit Review Modal (`SubmitReviewModal.jsx`)
- Verified stay review submission dialog for checked-out reservations.
- Star rating selector (1-5) and feedback textarea.
- Dispatches `engagementService.createReview`.

### Task 3: Guest Portal Dashboard (`GuestDashboardPage.jsx`)
- Route: `/dashboard` inside `<GuestLayout>`.
- Displays real loyalty points, Tier badge (Silver, Gold, Platinum), and dollar value equivalent.
- Displays active upcoming stay countdown card, quick actions to book rooms, view history, wishlist, and waitlist.

### Task 4: Stays Management (`MyBookingsPage.jsx` & `BookingDetailPage.jsx`)
- Route: `/my-bookings` and `/my-bookings/:id`.
- Filter tabs: Upcoming, Past, Cancelled.
- Actions:
  - "Download Tax Invoice (PDF)" calls `bookingService.downloadInvoice`.
  - "Request Cancellation" button triggers `CancellationRequestModal`.
  - "Write Review" button triggers `SubmitReviewModal` (only on checked-out stays).

### Task 5: Wishlist & Waitlist Pages (`WishlistPage.jsx` & `WaitlistPage.jsx`)
- Route: `/wishlist`: Saved rooms grid with one-click remove and book suite CTA.
- Route: `/waitlist`: Active subscriptions table with room type, dates, and unsubscribe button.

### Task 6: Routing & Build Verification
- Mount all guest routes in `client/src/App.jsx`.
- Run production build `npm run build` in `client/`.
