<objective>
Implement Phase 4: User Story 2 - Front Desk Operations & Permission-Gated Actions
1. Build `src/models/Payment.js` to store financial transactions with explicit `receivedByStaffId` attribution.
2. Build `src/services/desk.service.js` implementing:
   - `checkInGuest(bookingId, staffId)`: Validates `confirmed` status, sets status to `checked-in`, records checkInTimestamp.
   - `checkOutGuest(bookingId, staffId)`: Validates `checked-in` status, sets status to `checked-out`, transitions associated physical rooms' `housekeepingStatus` to `'dirty'`.
   - `recordInPersonPayment({ bookingId, amount, paymentMethod, transactionReference, notes, staffId, userPermissions })`: Validates staff PBAC for cash vs card, creates Payment document with `receivedByStaffId`, updates booking paymentStatus inside an ACID session.
   - `getOperationalOverview(query)`: Operational dashboard for front desk arrivals, departures, and active in-house guests with date/status filtering and pagination.
3. Build `src/controllers/desk.controller.js` and `src/routes/desk.routes.js` with permission guards (`checkin:manage`, `checkout:manage`, `payments:recordCash`, `payments:recordCard`, `bookings:view`).
4. Mount `/api/v1/desk` into `src/app.js`.
5. Implement complete integration test suite `tests/integration/desk.test.js` validating all success criteria and PBAC rejections.
6. Update Postman collection with the new Front Desk endpoints.
</objective>

  <description>
    Create `src/models/Payment.js` with schema:
    - `bookingId`: ObjectId ref Booking, required, indexed

<task type="auto" id="04-01-T2">
  <name>Implement Desk Operations Service</name>
  <description>
    Create `src/services/desk.service.js` with methods:
    - `checkInGuest(bookingId)`:
      - Validates booking exists.
      - Checks booking status is `confirmed` (rejects if `pending`, `cancelled`, or already `checked-in`).
      - Updates booking status to `checked-in`.
    - `checkOutGuest(bookingId)`:
      - Validates booking exists and status is `checked-in`.
      - Updates booking status to `checked-out`.
      - Updates all rooms in `booking.rooms` to `housekeepingStatus: 'dirty'`.
    - `recordInPersonPayment({ bookingId, amount, paymentMethod, transactionReference, notes, staffId, permissions })`:
      - Checks staff permissions: `payments:recordCash` if cash, `payments:recordCard` if offline-card.
      - In ACID transaction: creates Payment record with `receivedByStaffId: staffId`. Computes cumulative paid amount. Updates `booking.paymentStatus` ('paid' or 'partially_paid') and confirms booking if previously pending.
    - `getOperationalOverview(query)`:
      - Supports filtering by date (today/specified), arrival date, departure date, or booking status.
      - Returns paginated list of bookings with populated room and guest details.
  </description>
</task>

<task type="auto" id="04-01-T3">
