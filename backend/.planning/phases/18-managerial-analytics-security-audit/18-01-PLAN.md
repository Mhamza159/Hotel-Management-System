# Phase 18 Plan: Managerial Analytics, Bookings Oversight, Rooms Inventory & Security Audit

**Milestone:** Milestone 2 (Frontend Client SPA v2.0)  
**Requirements:** [FE-MGMT-01, FE-MGMT-02, FE-MGMT-03, FE-MGMT-04]  
**Styling System:** Staff Operations Cockpit (Material UI v5 wrapped in darkTheme, Inter font, #3FD0C9 live aqua accents, dense tables/charts, #0A0F1A background, #131A26 paper).

## Scope & Deliverables

1. **Admin Service (`client/src/services/admin.service.js`)**
   - Revenue & Occupancy analytics API bindings (`/api/v1/admin/analytics/revenue`, `/api/v1/admin/analytics/occupancy`).
   - Security audit logs API bindings (`/api/v1/admin/audit-log`).
   - Master bookings directory API bindings (`/api/v1/admin/bookings`).
   - Administrative room inventory CRUD & media API bindings (`/api/v1/rooms/admin/all`, `/api/v1/rooms`, `/api/v1/rooms/:id`, `/api/v1/rooms/:id/images`).

2. **Components & Dialogs**
   - `CreateEditRoomModal.jsx`: Create & edit room inventory specifications.
   - `RoomImagesModal.jsx`: Multi-image file upload to Cloudinary & photo management.
   - `BookingDetailModal.jsx`: Comprehensive reservation inspector (rooms, financials, guest).
   - `AuditPayloadModal.jsx`: Structured payload & changes inspector for immutable security logs.

3. **Cockpit Pages**
   - `AdminAnalyticsPage.jsx` (`/admin/analytics`): Revenue trends, ADR, RevPAR, and occupancy gauge using `@mui/x-charts`.
   - `AdminBookingsPage.jsx` (`/admin/bookings`): Global reservation directory with multi-filter search and pagination.
   - `AdminAuditLogsPage.jsx` (`/admin/audit-log`): Immutable audit trail with actor details, action badges, and payload inspection.
   - `AdminRoomsPage.jsx` (`/admin/rooms`): Physical room inventory management, status controls, and media upload.

4. **Integration & Build Verification**
   - Mount routes in `client/src/App.jsx` protected by `[ROLES.SUPER_ADMIN]`.
   - Verify `npm run build` succeeds with zero errors.
