<objective>
Implement Plan 06-01: Room Lifecycle, Housekeeping Status Workflow & Media Administration

1. Room Catalog Administration (PBAC Gated):
   - `POST /api/v1/rooms`: Create new room with unique roomNumber, type (single, double, deluxe, suite, presidential), pricePerNight, capacity, amenities, and photos (gated by `rooms:create`).
   - `PATCH /api/v1/rooms/:id`: Update room rates, capacity, or specifications (gated by `rooms:update`).
   - `DELETE /api/v1/rooms/:id`: Soft-delete room (marks `isDeleted: true`, `isActive: false`) to safeguard active/historical booking references (gated by `rooms:delete`).
   - `GET /api/v1/rooms/admin`: Admin list view of all rooms including inactive/dirty/maintenance rooms with status filters and pagination.

2. Housekeeping Cleanliness Workflow:
   - `PATCH /api/v1/rooms/:id/housekeeping`: Transition room housekeeping status (`clean`, `dirty`, `cleaning`, `maintenance`) with notes (gated by `housekeeping:update`).
   - Integration with check-out: Check-out marks rooms as `dirty`, housekeeping marks as `clean` after sanitation.
   - Maintenance Guard: Rooms in `maintenance` status are blocked from new reservations.

3. Media Pipeline (Multer & Cloudinary):
   - Configure Multer memory storage and Cloudinary uploader in `src/config/cloudinary.js`.
   - Store both `url` and `publicId` in Room `images` array.
   - Support remote deletion of image by `publicId` upon room update or photo removal.

4. Comprehensive Verification:
   - Integration tests in `tests/integration/room-admin.test.js` validating PBAC permissions, CRUD operations, housekeeping status transitions, and soft-delete safeguards.
   - Postman collection update with admin and housekeeping requests.
</objective>
