       - Allows super-admin even without explicit permission.
       - Allows user with exact permission string.
       - Denies user without permission with 403.
       - Denies unauthenticated requests with 401.
  </action>

       - `responseBody`: Mixed
       - `status`: Enum ['in-progress', 'completed']

       - Intercept `res.send`/`res.json` to record the completed response payload in `IdempotencyKey`.
    3. Write integration tests in `tests/integration/idempotency.test.js` validating duplicate request returns cached response with same status and body.
