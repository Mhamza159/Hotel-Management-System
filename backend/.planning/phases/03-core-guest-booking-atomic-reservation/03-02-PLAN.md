<task type="auto" id="03-02-T1">
  <name>Implement Atomic Booking Service</name>
  <description>
    Create `src/services/booking.service.js`:
    - `createBooking({ userId, roomIds, checkInDate, checkOutDate, numberOfGuests, specialRequests, paymentMethod, idempotencyKey })`:
      1. Validates inputs: checkInDate < checkOutDate, dates in future, roomIds is non-empty array.
      2. Starts a MongoDB session and transaction (`mongoose.startSession()`).
      3. In session, queries `Booking` for ANY active conflicting overlapping reservation for `roomIds` where `status: { $in: ['pending', 'confirmed', 'checked-in'] }` and `checkInDate < requestedCheckOut` and `checkOutDate > requestedCheckIn`. If found, aborts transaction and throws 409 Conflict `ApiError`.
      4. In session, fetches target `Room` documents to verify they exist, are active, not deleted.
      5. Computes authoritative total price: `nights * sum(room.pricePerNight)` with room rate snapshots.
      6. Creates `Booking` record with generated booking reference (`BK-${Date.now().toString(36).toUpperCase()}-${random}`), status `paymentMethod === 'pay_at_desk' ? 'confirmed' : 'pending'`, paymentStatus `unpaid`.
      7. Commits transaction and returns created booking.
    - `getGuestBookings(userId, query)`: Returns bookings for `userId` with pagination and sorting (`createdAt: -1`).
    - `getBookingById(bookingId, userId, role)`: Returns single booking details with ownership check (or super-admin / receptionist bypass).
  </description>
</task>
