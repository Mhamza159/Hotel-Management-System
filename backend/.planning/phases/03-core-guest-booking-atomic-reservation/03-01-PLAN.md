<task type="auto" id="03-01-T3">
  <name>Implement Room Availability Search Service</name>
  <description>
    Create `src/services/room.service.js`:
    - `findAvailableRooms({ checkInDate, checkOutDate, type, minCapacity, minPrice, maxPrice })`:
      1. Validates checkInDate < checkOutDate and checkInDate >= today.
      2. Finds all room IDs with overlapping active bookings:
         `Booking.find({ status: { $in: ['pending', 'confirmed', 'checked-in'] }, checkInDate: { $lt: requestedCheckOut }, checkOutDate: { $gt: requestedCheckIn } }).distinct('rooms.roomId')`.
      3. Queries `Room` where `_id: { $nin: bookedRoomIds }`, `isActive: true`, `isDeleted: false`, and matches optional filters (type, capacity, pricePerNight).
      4. Returns list of available room objects with pricing and details.
  </description>
</task>
