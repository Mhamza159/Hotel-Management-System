- Configure `client/tailwind.config.js`:
  - Base Ink: `#0A0F1A`
  - Surface: `#131A26`
  - Surface-2: `#1B2433`
  - Border: `#2A3547`
  - Text: `#ECEFF3`, Text Muted: `#8791A3`
  - Hospitality Gold: `#C9A15A`
  - Live Aqua: `#3FD0C9`
  - Statuses: Success `#3ECF8E`, Danger `#F2545B`, Warning `#E8A33D`
- In `client/src/index.css`: Import Google Fonts (`Fraunces` for luxury display headings, `Inter` for UI & body).
- Create `client/.env` and `client/.env.example` with `VITE_API_BASE_URL=http://localhost:5000/api/v1`.

### Task 3: Configuration & Custom Themed MUI v5 (T007 - T008)
- Create `client/src/config/constants.js` with frozen `ROLES`, `PERMISSIONS`, `BOOKING_STATUS`, `PAYMENT_STATUS`, `PAYMENT_PROVIDERS`, `REFUND_TIERS`, `ROOM_TYPES`, `HOUSEKEEPING_STATUS`.
- Create `client/src/config/muiTheme.js`:
  - Override `palette` with dark mode, background `#0A0F1A`, paper `#131A26`, primary aqua `#3FD0C9`, secondary gold `#C9A15A`.
  - Set `typography.fontFamily` to `'Inter', sans-serif`.
  - Override `MuiButton`, `MuiPaper`, `MuiCard` with 8px radius and custom elevations.

### Task 4: Axios Resilience Layer & Client Stores (T009 - T012)
- Implement `client/src/services/api.js`:
  - Request Interceptor: Attach `Authorization: Bearer <accessToken>`. On `POST /bookings`, attach `Idempotency-Key: crypto.randomUUID()`.
  - Response Interceptor: Unwrap `response.data.data`. Catch 401, enqueue failed requests, call `POST /api/v1/auth/refresh-token`, update tokens in `useAuthStore`, and replay queue.
- Implement `client/src/stores/useAuthStore.js`:
  - `user`, `accessToken`, `refreshToken`, `role`, `permissions`, `setAuth()`, `logout()`, `updateUser()`.
- Implement `client/src/stores/useBookingDraftStore.js`:
  - `selectedRooms`, `checkInDate`, `checkOutDate`, `numberOfGuests`, `specialRequests`, `paymentMethod`.
- Implement `client/src/stores/useUIStore.js`:
  - `isCommandPaletteOpen`, `toggleCommandPalette()`, `isConciergeOpen`, `toggleConcierge()`.

### Task 5: Core Shared Components & PBAC Guards (T013 - T018)
- Implement `client/src/components/common/Can.jsx`:
  - Checks `user.role === 'super-admin' || user.permissions.includes(permission)`.
  - Renders children on match; renders `null` (invisible, never disabled) on mismatch.
- Implement `client/src/components/common/KeycardLoader.jsx`: Gold line sweep animation for waits.
- Implement `client/src/components/common/BookingStatusBadge.jsx`: 7 status badges with appropriate semantic colors.
- Implement `client/src/components/common/EmptyState.jsx`: Directive text with line-drawn key/bell icon.
- Implement `client/src/components/common/Toast.jsx` & `client/src/components/common/ProtectedRoute.jsx`.
- Implement base `client/src/App.jsx` and `client/src/main.jsx` mounting `QueryClientProvider`, `BrowserRouter`, and `ThemeProvider`.
