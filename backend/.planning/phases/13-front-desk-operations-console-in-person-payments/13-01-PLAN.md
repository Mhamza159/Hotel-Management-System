<objective>
Execute Phase 13: Front Desk Operations Console & In-Person Payments:

### Task 1: Front Desk HTTP Service (`desk.service.js`)
Implement `deskService` with backend routes:
- `getOverview(params)`: `GET /api/v1/desk/bookings` (params: `type: 'arrivals' | 'departures' | 'in-house'`, `date`, `page`, `limit`)
- `checkIn(id)`: `PATCH /api/v1/desk/bookings/:id/check-in`
- `checkOut(id)`: `PATCH /api/v1/desk/bookings/:id/check-out`
- `recordPayment(id, payload)`: `POST /api/v1/desk/bookings/:id/payments` (payload: `{ amount, paymentMethod, reference }`)
- `getCancellationRequests(params)`: `GET /api/v1/desk/cancellation-requests`
- `getCancellationReview(id)`: `GET /api/v1/desk/bookings/:id/cancellation-review`
- `approveCancellation(id)`: `PATCH /api/v1/desk/bookings/:id/cancel-approve`
- `rejectCancellation(id, payload)`: `PATCH /api/v1/desk/bookings/:id/cancel-reject`

### Task 2: Staff Operations Shell (`StaffLayout.jsx`, `StaffSidebar.jsx`, `StaffHeader.jsx`)
- `StaffLayout`: Responsive sidebar navigation + sticky header + main operations area.
- `StaffSidebar`: Dynamic PBAC items:
  - `/desk` (Front Desk Arrivals/Departures) -> requires `bookings:view`
  - `/desk/cancellations` (Cancellation Queue) -> requires `bookings:view`
  - `/housekeeping` (Cleanliness Board) -> requires `housekeeping:update`
  - `/admin/bookings` (Global Bookings) -> requires `analytics:view`
  - `/admin/rooms` (Room Inventory) -> requires `rooms:view`
  - `/admin/staff` (Staff & PBAC) -> requires `staff:manage`
  - `/admin/analytics` (Revenue/Occupancy) -> requires `analytics:view`
  - `/admin/audit-log` (Security Audit) -> requires `audit:view`
- `StaffHeader`: Hotel title, today's date badge, ⌘K search prompt, user profile avatar, and sign-out button.

### Task 3: In-Person Payment Dialog (`RecordPaymentDialog.jsx`)
- Modal dialog with Amount, Payment Method (`cash` or `offline-card`), Reference notes.
- Submits to `deskService.recordPayment`, updates payment status to `completed`, and closes modal.

### Task 4: Front Desk Operational Flight-Ops (`DeskDashboardPage.jsx`)
- Tabs: `Arrivals Today`, `Departures Today`, `Currently In-House`.
- DataGrid with columns: Reference, Guest Name, Room(s), Check-In Date, Check-Out Date, Total Amount, Paid Amount, Payment Status, Booking Status, Actions.
- Quick Actions:
  - `Check In` button: triggers `deskService.checkIn`. Displays directive alert if room is dirty.
  - `Check Out` button: triggers `deskService.checkOut`.
  - `Record Payment` button: opens `RecordPaymentDialog` if balance remains.
  - `Invoice` button: downloads PDF Tax Invoice.

### Task 5: Routing & Build Verification
- Mount `/desk` in `client/src/App.jsx` under `StaffLayout` and `ProtectedRoute`.
- Run production build `npm run build` in `client/`.
