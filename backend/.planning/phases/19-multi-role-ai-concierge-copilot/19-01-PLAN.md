# Phase 19 Plan: Multi-Role AI Concierge & Administrative Copilot

**Milestone:** Milestone 2 (Frontend Client SPA v2.0)  
**Requirements:** [FE-AI-01, FE-AI-02, FE-AI-03]  
**Styling System:** Dual-Register Architecture (Guest Side: Ink/Gold/Surface luxury chat drawer; Staff Side: Live Aqua/Dark Slate operations copilot with two-phase mutation confirmation).

## Scope & Deliverables

1. **AI Chat Service (`client/src/services/chat.service.js`)**
   - Role-scoped endpoint dispatches (`/chat/user`, `/chat/staff`, `/chat/admin`).
   - Mutation confirmation execution (`/chat/admin/confirm`).

2. **Components & Modals**
   - `ChatDrawer.jsx`: Universal floating AI concierge drawer with quick prompt pills, live streaming animation, and role awareness.
   - `ConfirmationActionModal.jsx`: Two-step human gate modal prompting confirmation before executing signed JWT mutation tokens.

3. **Pages**
   - `ConciergePage.jsx` (`/concierge`): Dedicated immersive guest luxury AI concierge page for suite recommendations, itinerary planning, and stay queries.
   - `AdminCopilotPage.jsx` (`/admin/copilot`): Administrative AI Command Cockpit with tool suggestions, dry-run inspection, and confirmation protocol.

4. **Integration & Build Verification**
   - Wire `/concierge` for guests/public and `/admin/copilot` under `StaffLayout` in `client/src/App.jsx`.
   - Update `StaffSidebar.jsx` and `Navbar.jsx` with AI Concierge / Copilot quick links.
   - Run `npm run build` and ensure 0 errors.
