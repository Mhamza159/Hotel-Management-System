<objective>
Implement Plan 08-01: Immutable Audit Logging, Managerial Analytics Pipelines & Role-Governed AI Chat Assistant

1. Immutable Audit Logging (MGMT-01):
   - `AuditLog` Model with `actorId`, `action`, `targetType`, `targetId`, `beforeState`, `afterState`, `ipAddress`, and immutable `createdAt`.
   - `AuditService.logAction(...)` helper that automatically appends records.
   - Hook into staff permission modifications, room rate updates / deletions, and cash receipts.
   - `GET /api/v1/admin/audit-log`: Paginated audit log endpoint protected by `audit:view` permission or `super-admin`.

2. Managerial Analytics Pipelines (MGMT-02):
   - `GET /api/v1/admin/analytics/revenue?from=YYYY-MM-DD&to=YYYY-MM-DD`:
     Calculates Total Revenue, ADR (Average Daily Rate = Room Revenue / Rooms Sold), and RevPAR (Revenue Per Available Room = Room Revenue / Total Available Rooms).
   - `GET /api/v1/admin/analytics/occupancy?date=YYYY-MM-DD`:
     Computes active room occupancy percentage for the hotel on the specified date.
   - Protected by `analytics:view` permission or `super-admin`.

3. Role-Governed AI Assistant with Confirmation Gates (MGMT-03):
   - `ChatSession` Model for thread tracking.
   - `POST /api/v1/chat/user`: Scoped to authenticated guest (read-only: check room availability, get room details, view personal bookings).
   - `POST /api/v1/chat/staff`: Scoped to receptionist / staff (inspect booking status, date range arrivals, occupancy stats).
   - `POST /api/v1/chat/admin`: Super-admin assistant with destructive tool confirmation protocol. State-altering mutations (e.g. `prepareBookingCancellation`) return a signed JWT `confirmationToken` requiring secondary user confirmation before any mutation executes.

4. Integration Testing & Verification:
   - 100% automated test coverage in `tests/integration/analytics-audit-chat.test.js`.
   - Update Postman collection with `Management, Audit & AI Assistant (Phase 8)` folder.
</objective>
