<objective>
Execute Phase 16: Staff Management & Dynamic PBAC Matrix:

### Task 1: Staff HTTP Service (`staff.service.js`)
- `getStaff(params)`: Calls `GET /api/v1/auth/staff` (params: `{ role, search }`).
- `createStaff(payload)`: Calls `POST /api/v1/auth/staff` (payload: `{ name, email, password, phone, role }`).
- `getPermissionsMetadata()`: Calls `GET /api/v1/auth/permissions` (returns `{ roles, permissions, roleDefaultPermissions }`).
- `updatePermissions(id, payload)`: Calls `PATCH /api/v1/auth/users/:id/permissions` (payload: `{ role, permissions, resetToDefault, isActive }`).

### Task 2: Create Staff Modal (`CreateStaffModal.jsx`)
- Dialog to create receptionist, housekeeping, or super-admin accounts.
- Form fields: Name, Email, Password, Phone, Role.
- Dispatches `staffService.createStaff` and triggers table refresh.

### Task 3: Staff Directory Page (`StaffDirectoryPage.jsx`)
- Route: `/admin/staff`.
- Dense Material UI table displaying all active staff:
  - Avatar, Name, Email, Phone, Role badge, Active Status, Permissions Count.
  - "Configure PBAC Matrix" button linking to `/admin/staff/:id/pbac`.
- Top button: "+ Create New Staff Member".

### Task 4: Split-View PBAC Matrix Page (`StaffPbacMatrixPage.jsx`)
- Route: `/admin/staff/:id/pbac` (and `/admin/staff/pbac`).
- Split-View layout (Section 6b):
  - **Left Panel:** Staff List with active selected member highlighted.
  - **Right Panel:** Permission Matrix for selected staff member:
    - Role selector dropdown (changes role and permissions dynamically).
    - "Reset to Role Defaults" button.
    - Category-grouped switches:
      1. Bookings (`bookings:view`, `bookings:create`, `bookings:confirm`, `bookings:cancel`)
      2. Front Desk (`checkin:manage`, `checkout:manage`, `housekeeping:update`)
      3. Payments (`payments:recordCash`, `payments:recordCard`, `payments:refund`)
      4. Room Inventory (`rooms:view`, `rooms:create`, `rooms:update`, `rooms:delete`, `rooms:priceUpdate`)
      5. Oversight & Intelligence (`analytics:view`, `audit:view`, `staff:manage`, `coupons:manage`, `waitlist:manage`)
    - Switch loading indicator while dispatching update.

### Task 5: Routing & Build Verification
- Mount `/admin/staff` and `/admin/staff/:id/pbac` in `client/src/App.jsx`.
- Run production build `npm run build` in `client/`.
</objective>
